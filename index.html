Electricity Consumption Forecasting (Time Series ML)

Problem

Forecasting electricity consumption requires models that can handle time-dependent patterns correctly. A major challenge was avoiding data leakage, where information from the future unintentionally influences the model, leading to unrealistic performance. The objective was to build forecasting models on over 2 million hourly observations and evaluate them in a way that reflects real deployment conditions.

Goal

Build forecasting models using proper temporal validation and feature engineering that respects time ordering, ensuring reliable and realistic performance.

Data

  • Over 2 million hourly electricity consumption records
  • Created temporal features including lag variables, rolling statistics, and calendar features
  • Identified and investigated potential sources of data leakage
  • Used time-aware train/test splits to preserve temporal structure

Approach

  • Compared SARIMA, Random Forest, and XGBoost models
  • Engineered lag features and rolling statistics (mean, standard deviation)
  • Added calendar features such as hour, day, and month
  • Identified and removed features that introduced leakage from future observations
  • Used time-series cross-validation with strict temporal ordering
  • Compared performance against a baseline model to measure real improvement

Results

Achieved 42.7% error reduction compared to baseline using Random Forest

Removing leakage resulted in more realistic and trustworthy model performance

Ensemble methods outperformed traditional time series baselines when properly validated

Technical Implementation

  • Python with scikit-learn for model development and evaluation
  • Random Forest and XGBoost for ensemble modeling
  • pandas for time series processing and feature engineering
  • matplotlib for visualization and error analysis
  • SARIMA used as a classical baseline

Key Engineering Contributions

  • Detected and removed features causing data leakage
  • Implemented proper time-series validation methodology
  • Built and compared multiple forecasting approaches
  • Engineered temporal features while preserving causality

Key Takeaways

This project reinforced how easy it is to introduce leakage in time series problems, and how important proper validation is. It also showed that careful feature engineering and evaluation matter as much as model choice when building reliable forecasting systems.

Pan-Tissue Epigenetic Clock (DNA Methylation ML)

Problem

Biological age provides insight into cellular state and aging, but it cannot be measured directly. DNA methylation at CpG sites offers a useful proxy, though predicting age from these profiles is challenging due to high dimensionality, strong feature correlations, and variation across tissues and species.

Goal

Build a machine learning model that predicts biological age from DNA methylation data across multiple mammalian tissues, while maintaining robustness and interpretability.

Data

  • Over 12,000 mammalian samples across multiple species
  • 37,000 CpG methylation features per sample
  • High-dimensional feature space with significant multicollinearity
  • Limited sample sizes for some species, requiring careful validation

Approach

  • Compared Elastic Net, LightGBM, and neural network models
  • Used sparse regularization to handle high dimensionality and correlated features
  • Performed hyperparameter optimization using Optuna
  • Applied 5-fold cross-validation to ensure reliable performance estimates
  • Focused on balancing predictive accuracy with interpretability

Results

Achieved MAE of 0.076 (relative age)

Strong correlation between predicted and actual age (Pearson r = 0.937)

Elastic Net outperformed gradient boosting and neural network models

Model remained stable even with smaller per-species sample sizes

Technical Implementation

  • Python with scikit-learn for Elastic Net modeling
  • LightGBM for gradient boosting comparison
  • PyTorch / TensorFlow for neural network experiments
  • Optuna for hyperparameter optimization
  • pandas and NumPy for data processing and analysis

Key Engineering Contributions

  • Built models on high-dimensional biological data (37,000 features)
  • Applied regularization to manage multicollinearity and overfitting
  • Compared linear, ensemble, and deep learning approaches
  • Implemented cross-validation suitable for limited biological datasets

Key Takeaways

This project showed that simpler regularized linear models can outperform more complex approaches when working with high-dimensional biological data. It also reinforced the importance of regularization, careful validation, and model interpretability in scientific machine learning.

Mapping Cortical Connectivity Gradients (Master's Thesis)

Problem

The cerebral cortex is organized along a gradient from sensory regions to higher-order cognitive areas, but the structural connectivity patterns underlying this organization are not fully understood. The goal was to quantify how connection strength and distance vary across the cortex, and determine whether these patterns reflect known cortical hierarchy.

Data & Methods

  • 77 subjects with diffusion MRI data
  • Lausanne500 atlas (~450 cortical regions)
  • Constructed structural connectomes using diffusion tractography
  • Computed geodesic distances across the cortical surface
  • Modeled connectivity decay using variogram-based Gaussian fitting

Approach

  • Applied distance-dependent thresholding to preserve meaningful long-range connections
  • Extracted two key features per region:
    • Range — typical connection length
    • Sill — strength of local connectivity
  • Correlated these features with the principal cortical gradient (sensory → transmodal axis)
  • Used permutation testing to validate statistical significance

Results

Transmodal regions showed longer connection ranges and weaker local connectivity

Connection range correlated with cortical hierarchy:

  • Left hemisphere: r = 0.26, p_perm = 0.00014
  • Right hemisphere: r = 0.18, p_perm = 0.00723

Connection range increased with distance from sensory cortex:

  • Left hemisphere: r = 0.41
  • Right hemisphere: r = 0.44

Variogram models showed strong fit stability (R² ≈ 0.98)

Technical Implementation

  • Python for data processing, modeling, and statistical analysis
  • Diffusion MRI tractography for connectome construction
  • Variogram modeling to quantify spatial connectivity structure
  • Permutation testing for statistical validation
  • Network visualization and analysis

Key Contribution

This work showed that connection length is more strongly associated with cortical hierarchy than local connection strength. The results support the idea that long-range connectivity plays a key role in organizing the cortex, particularly in higher-order regions.

Key Takeaways

This project gave me experience working with high-dimensional scientific data, spatial modeling, and statistical validation. It also reinforced the importance of careful quantitative analysis when studying complex biological systems.

Evolution of the Carnivore Gut Microbiome (Bachelor's Thesis)

Problem

Gut microbiomes play an important role in digestion and host health, but how these microbial communities evolve alongside their hosts over long timescales is not fully understood. This project investigated whether microbiome composition reflects host evolutionary relationships and whether microbial lineages persist across millions of years.

Goal

Reconstruct and compare gut microbiomes from extinct and living carnivores to identify conserved microbial lineages and examine host–microbiome evolutionary relationships.

Data

  • 8,685 microbial taxa across 19 mammalian species
  • Ancient DNA samples approximately 40,000–50,000 years old
  • Shotgun metagenomics and 16S rRNA sequencing data
  • Included both extinct species (cave hyena) and modern carnivores

Approach

  • Processed ancient and modern microbiome sequencing data
  • Built microbial abundance tables from sequencing results
  • Constructed host phylogenetic trees using mitochondrial DNA
  • Applied probabilistic evolutionary modeling to identify conserved microbial lineages
  • Performed diversity analysis using UniFrac distances and principal coordinate analysis
  • Used permutation testing to evaluate statistical significance

Results

Identified dominant microbial phyla across carnivore species:

  • Firmicutes (42%)
  • Proteobacteria (18%)
  • Actinobacteria (16%)

Found significant association between microbiome composition and host evolutionary relationships

Identified conserved microbial genera across species, including Clostridium and Lachnoclostridium

Successfully reconstructed the gut microbiome of an extinct cave hyena from ancient DNA

Technical Implementation

  • Ancient DNA processing and microbiome analysis pipelines
  • Shotgun metagenomic and 16S rRNA data analysis
  • Phylogenetic reconstruction using mitochondrial DNA
  • Probabilistic evolutionary modeling
  • Python and R for data processing, statistical analysis, and visualization

Key Contribution

This work showed that carnivore gut microbiomes retain conserved bacterial lineages across evolutionary timescales, supporting the idea that hosts and their microbiomes evolve together.

Key Takeaways

This project gave me experience working with sequencing data, high-dimensional biological datasets, and statistical analysis. It also showed how computational methods can be used to study evolutionary patterns in complex biological systems.
