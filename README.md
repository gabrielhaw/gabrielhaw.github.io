# Websites-R-US 🌐

A personal portfolio website built to showcase my projects, skills, and experience and, ideally, to finally get a callback.

Live site: **[gabrielhaw](https://gabrielhaw.github.io)**

---

## 🚀 About This Project

This site serves as my personal web portfolio. It highlights:
- Selected projects (academic + personal)
- Technical skills and tools I actually use
- A short bio and background
- Contact information for recruiters, collaborators, or curious humans

The goal is simple: **clear, fast, and honest representation of my work** no bloated frameworks or unnecessary fluff.

---

## 🛠 Tech Stack

- **Tailwind CSS**
- **Preline UI**
- **Basic JavaScript**
- **GitHub Pages** for hosting

Built locally without a heavy build system just clean, readable front-end code.

---

## ✨ Features

- Responsive design
- Clean UI with accessible typography
- Project cards with descriptions and links
- Lightweight animations and UI components
- Fast load times (because nobody waits)

---

## 🧠 Why This Exists

Job applications are a numbers game but this site is my attempt to:
- Show real work instead of buzzwords
- Make it easy to evaluate my skills quickly
- Give context beyond a one-page résumé

If you’re hiring and reading this: **thanks for actually clicking the repo.**
